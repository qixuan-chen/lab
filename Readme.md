## update website guide 

### clone the repository

First, make sure you have Hugo and Git installed. If not, please refer to this website. https://gohugo.io/getting-started/quick-start/



If this is your first time using this device, or if you do not have a local repository yet, there are several ways to connect to a GitHub repository remotely.

```{zsh}
# the default repository name will be origin 
git clone https://github.com/qixuan-chen/lab.git
```

Alternatively, you can download the source files, extract them to a directory, and then manually connect the folder to the remote repository.

```{zsh}
# use your own address 
cd ~/Downloads/test-main
git init
git branch -M main
git remote add origin https://github.com/qixuan-chen/lab.git
git add .
git commit -m "Initialize local repository from downloaded files"
git pull origin main --allow-unrelated-histories
git push -u origin main
```

If you already have a local repository

```{zsh}
# cd to the root directory
```

### make some preliminary check

```{zsh}
# check what are included in the directory
ls
# check git status. Make sure your branch is up to date with the latest commits and that there are no uncommitted 
# changes
git status
# check remote repository
git remote -v
# check branch
git branch
```

If you want to save and push your local modification

```{zsh}
git add .
git commit -m "Update website"
git pull origin main
git push origin main
```

If you don't need your local modification anymore

```{zsh}
# This command will delete any local changes that have not been committed yet
git fetch origin
git reset --hard origin/main
```

### modify the content you want

```{zsh}
hugo server -D
```

then open the website with address, When you finish, run following code.

```{zsh}
hugo serve
```

```{zsh}
git status
git add .
git commit -m "describe the modification"
git push 
```

Finally, go back to your GitHub repository page and check the Actions tab. It will show the new website generated by your latest changes.
